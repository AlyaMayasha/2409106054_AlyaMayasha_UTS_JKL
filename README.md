# 2409106054_AlyaMayasha_UTS_JKL

## Deskripsi

Project UTS Jaringan Komputer Lanjut untuk melakukan integrasi dan otomasi jaringan menggunakan Python.

Project ini menggabungkan beberapa tahap pemeriksaan dan pengelolaan jaringan, yaitu:

- Identitas perangkat dan cabang
- Akses SSH
- Monitoring SNMP
- Pembuatan pesan NETCONF
- Analisis telemetry
- Integrasi seluruh modul melalui `main.py`
